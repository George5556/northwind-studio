# NORTHWIND — архитектура и интерьеры

Одностраничный сайт-портфолио вымышленного бюро архитектуры и интерьеров. Премиальный минимализм, брутальная типографика, тёмная тема по умолчанию и светлая через `prefers-color-scheme`.

**Демо:** https://george5556.github.io/northwind-studio/

## Стек

- Чистый HTML, CSS и JavaScript. Без фреймворков, сборщиков, npm-зависимостей и CDN.
- Только системные шрифты и локальные CSS/SVG-композиции вместо фотографий.
- ES-модуль при загрузке по HTTP и классический скрипт при открытии через `file://` — консоль остаётся чистой в обоих режимах.

## Что внутри

- Кинетический герой: побуквенное появление, маски, параллакс по указателю.
- Sticky-горизонтальная галерея из пяти проектов на десктопе; вертикальный fallback на планшете и мобильном.
- Reveal-анимации на `IntersectionObserver` со стаггером, счётчики цифр, прогресс прокрутки.
- Кастомный магнитный курсор и магнитные кнопки только для точного указателя.
- Полная поддержка `prefers-reduced-motion`: анимации отключаются, контент виден сразу.
- Доступность: семантическая разметка, один `h1`, skip-link, видимый фокус, ARIA, нативная модалка меню, контраст AA.
- Адаптивность от 360 до 1440+ без горизонтальной прокрутки.
- Метаданные: title, description, Open Graph, Twitter Card, favicon, JSON-LD.

## Локальный запуск

Сайт работает и без сервера — достаточно открыть `index.html` двойным кликом.

Для проверки HTTP-режима (и ES-модуля):

```bash
npx serve .
# или
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Структура

```
index.html      разметка, метаданные, диалог мобильного меню
styles.css      токены, сетка, темы, CSS-графика, адаптив
script.js       прелоадер, скролл, галерея, reveal, курсор, меню
assets/og.png   изображение для социальных сетей 1200×630
```
